為什麼它不會倒？（直覺 → 公式）

直覺：沒轉的時候，重力把飛輪往下拉，它當然會倒。轉起來以後，飛輪有一支很長的「角動量箭頭」L。重力產生的力矩 τ 不會把箭頭變短，只會一直把箭頭的尖端往 τ 的方向推一點點，而 τ 永遠跟 L 垂直，所以箭頭只能繞圈。這個繞圈就是進動。

L = I ω　　τ = r × F　　ΔL = τ Δt

每過 Δt，L 轉過的角度是 ΔL / L = τΔt / (Iω)，所以

Ω = τ / (I ω)

轉越快（ω 大）或飛輪越重越大（I 大），進動越慢；力矩越大，進動越快。配重讓 τ 變成 0 時，進動停止；τ 變號，進動反向。

章動：「從靜止放手」時，飛輪一開始還沒有進動速度，會先往下掉一點再被帶起來，軌跡出現小圈圈或尖點。這是章動，摩擦會讓它慢慢消失。按「平順放手」則一開始就給剛好的進動速度，沒有章動。

往旁邊推卻往上跑：水平推力產生的力矩是鉛直方向的，它讓 L 往上或往下轉，所以你推它「水平」，它卻「抬頭」或「低頭」。這就是拿著陀螺儀時手被頂的感覺。

模型：一端支點的重對稱陀螺，用拉格朗日方程式數值積分（RK4，步長 0.5 ms）。軸最多下垂到水平以下 50°。

這艘船的模型

轉盤裝在一個「左右方向的鉸鏈」上，只能往船頭或船尾倒。轉盤架的重心在鉸鏈下方，所以沒有外力時會自己回正。

船往右搖時，船帶著轉盤一起繞「船頭方向」的軸轉，也就是對轉盤施加指向船頭的力矩 τ。轉盤的角動量 L 會往 τ 的方向偏，但鉸鏈只允許前後倒，所以轉盤往前或往後倒（看 L 朝上還是朝下）。

I架 θ'' = L φ' − k θ − c θ'

θ 是轉盤前後倒的角度，φ' 是船搖晃的角速度。轉盤倒下的同時，也會反過來給船一個反向力矩 −L θ'，把船推回去，這就是船變穩的原因（見「轉子開關對照」）。

如果你們的實體轉盤是直接固定在船上（沒有鉸鏈），效果會變成整艘船一起進動，演示前要先確認支撐方式。

為什麼有轉的船比較穩？

直覺：浪想讓船左右搖，船就得帶著轉盤一起轉。但轉盤有角動量，被扭的時候不會乖乖跟著，而是「往旁邊倒」（往船頭或船尾）。它倒下的同時會頂回船一個反向力矩，把搖晃抵銷掉。鉸鏈的摩擦再把這份能量消耗掉。

I船 φ'' = −k φ − c φ' − L θ' + τ浪

−L θ' 就是轉盤頂回來的力矩。L 越大（轉越快），頂回來越多。下方的圖是兩艘船的傾斜角對時間。

把「鉸鏈阻尼」拉到 0 試試：搖晃還是會變小（共振頻率被轉盤改掉了），但能量只是在船和轉盤之間來回換。真的船用陀螺穩定器（例如 Seakeeper）也是在鉸鏈上加剎車來吸收能量。
